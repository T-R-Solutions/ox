# Visual reference integration successor

## Analysis and decisions

Inventory: 3,033 files/archive members; 1,359 distinct byte contents. Every member
has source, hash, duplicate identity and a type-based disposition in members.json.
This is not individual semantic approval of all 334 R12 PNGs or all historical files.
107 source headings and 173 bullet/emphasis clauses map to the maintained English
contract. Tables/code/examples remain within their mapped source sections; a section
map is not a claim that every requirement is implemented. v4 supplies operational
breadth, v3 preserves legacy detail. R13 and alternative typefaces remain proposals.

The useful additional contribution is desktop region hierarchy: embedded files and
tabs → primary code → origin inspector → tools. Architecture gains a directional
Cargo-dependency map; agent surfaces gain a role/responsibility/instance table.
No browser runtime, engine, new dependency or third-party icon set is imported.
Existing external skill absorption remains adequate; no additional skill identity
is justified. The incorporated native method was used to separate presentation
selection from effects, inspect wide/narrow geometry and collect source-bound captures.

## Verification and limits

Rust tests cover bounded selection and absence of Controller/generation effects,
in addition to preserved artifact identity, invalidation, cancellation and timeout
checks. Clippy checks the actual Iced 0.14 consumer. Contrast roles are unchanged;
96 previously defined opaque pairs are recalculated. Generated role source matches.

Native Mutter/Wayland harness uses real key input, captures file and tool selection,
map/table composition, theme/density, Escape, actual controlled-task artifact and
natural app exit. Initial wide/narrow observations prompted less editor header
chrome and separate tree/tab focus targets; final observations are in native-*-final.
Observed source identities accompany the logs; source screenshots remain historical.
Reference images inspected in this iteration: architecture, agents and appearance;
the earlier master/montage inspection is preserved. No browser rendering or AT test
is claimed. Six X11 tests remain explicitly ignored in ordinary cargo test.

## Pending work and resumption

Broad original acceptance remains open: complete independent clause-level semantic
review, remaining historical image/prototype inspection where it may change a design
decision, licensed icon-system adaptation, graph pan/zoom, resizable panes, document
editing and real services. The source inventory does not promote these to accepted.
AT and full X11/window/theme/failure matrices require distinct observation. Resume
from the actual consumer and explicit criteria; never substitute a screenshot for
engine behavior or copy historical acceptance onto changed inputs.

AGENTS, DESIGN, source coverage, component contracts, surface map, SDD plan/tasks and
evidence are updated. Prior affected evidence is retained byte-for-byte separately;
current undecided criteria remain INCONCLUSIVE/UNVERIFIED. No commits/publication.
