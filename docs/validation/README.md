# Validation records

This directory retains dated observations, snapshots and feature-specific reports.
A report's title or historical APPROVED statement is not current acceptance.
Current criterion states are owned by sdd/features/*/evidence.json and its delimited
convergence projection; current input hashes must still match.

- [Audit correction, 17 November 2026](audit-correction-20261117/spec.md): current correction scope and linked reports; no global product approval.
- [Original governance report](report.md): governance-externalization-001, 26 October 2026, before the Rust product.
- [Normative coverage ledger](normative-coverage.md): historical rule-text coverage, not evidence that every product control is implemented or absent today.
- [Feature index](../../sdd/features/README.md): maintained routes to product and governance acceptance.

Dates and identifiers belong to their observations. Preserve old artifact bytes and
origins. Files named before/ are snapshots, not live guides. Missing temporary or
ignored raw logs limit reproducibility and must not be replaced with invented output.
Operational .local logs use separate two-date retention; this directory is not a
promise that every local .log file is tracked in Git. Use the sharing contract before
exporting; this index does not authorize publication or historical cleanup.
