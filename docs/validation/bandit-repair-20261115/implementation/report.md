## P2 successor — filename-independent sample hashing

Independent review rejected the earlier `sha256sum -- "${sample}"` path because GNU sha256sum prefixes escaped filenames with a backslash; truncating its output to 64 characters then corrupts the digest for backslash/newline directory names. Rejected source/test/config bytes and identities are retained in `rejected-p2/` and `rejected-p2.json`. The repair reads sample bytes through stdin: `sample_sha=$(sha256sum <"${sample}") || return 2`.
