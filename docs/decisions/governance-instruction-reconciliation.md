## Bounded consumer correction discovered during integration

Independent-copy tests exposed the distinction between a local checkout and its
existing governance export. Copy/archive writers now emit an exact versioned
`.ox-governance-copy.json` receipt, included in the export/archive manifest. It
identifies consumer mode; public bytes do not authenticate who created it, confer
permissions or prove OS isolation. A conflicting live checkout (.git, application,
config or agents) rejects the receipt. Missing receipt always retains local checks.

Only records excluded by the existing product_record allowlist may be absent in
that declared copy; their retained predecessors remain authenticated. Required
exported paths and snapshot files cannot be missing. Agent config/profiles are
exported solely as observed `.bin` evidence with pinned identities, never installed
under .codex. Local check-ox must compare all 14 live sources against snapshots
before feature acceptance; drift, missing sources and symlinks fail. The immutable
audit's one profile link may resolve to its observed snapshot only in this explicit
consumer mode, with exact source/destination/content identities. Other links fail.

The docs index had a preexisting, unmapped agent-guide row. It is left unchanged;
removing exactly that row recovers the pinned 0f6e901... complete-repair successor.
This lineage repair does not rewrite historical hashes or authorize index drift.
No source allowlist, product scope, agent installation or publication is expanded.
