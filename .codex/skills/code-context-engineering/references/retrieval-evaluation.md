# Evaluate retrieval, then downstream utility

Create a corpus with held-out queries and independently annotated relevant locations. Track exact-match/range correctness separately from semantic usefulness. Count an obsolete result as a freshness failure even if its text remains plausible.

Compare path/text search, structural indexing and optional semantic enrichment under the same query set and snapshot. Record index build/update work, query latency, memory and retrieved volume; report precision and recall with their denominators. Do not select embeddings merely because a graph or an agent exists.

For downstream claims, run paired task evaluations with comparable budgets and permissions. Retrieval metrics do not prove task completion. Synthetic fixtures can verify mutation invalidation and range identity now; claims about real repositories, multilingual coverage or agent success require observed evaluations on those inputs.
