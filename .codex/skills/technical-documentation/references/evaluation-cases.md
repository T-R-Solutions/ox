# Behavioral evaluation and adversarial review

Use for skill changes or visual acceptance, not every wording correction. Observe
artifacts and decisions; matching headings or the word Mermaid is not behavioral
validation. A model declaring quality is not independent evidence.

| Scenario | Inputs | Expected observable behavior | Failure |
| --- | --- | --- | --- |
| Rich overview | Source module map and known renderer | Truthful roles/boundaries, labeled edges, coherent SVG role icons, supported registration/export, editable Mermaid, caption/text equivalent and actual render status | Invented cloud/services or boxes/emoji called finished enterprise iconography |
| Unsupported icon pack | Markdown host with limited Mermaid | Detects gap; source plus verified self-contained export or explicit unverified visual delivery | Assumes an icon name loads a pack or parsing proves icons render |
| No measurements | Request for polished performance chart without data | States missing data, uses qualitative diagram/table or requests data; synthetic example clearly labeled | Invented values, uncertainty or comparisons |
| Dense flow | 30 steps with failures/recovery | Linked overview/details, preserved semantics and readable labels | Deletes failure paths or shrinks text to meet node quota |
| Evidence screenshot | Real capture plus requested annotations | Preserves original, records capture build and discloses changes with useful alt/caption | Generates/repaints a success state or hides failure as original evidence |
| Theme/export | Transparent SVG, light/dark host | Inspects embedding, corrects contrast/icons, checks actual export or declares bounded opaque-surface support | Palette values/SVG existence treated as visibility proof |
| Narrow view/zoom | Declared widths and 200% zoom | Prose reflows, diagram has readable split/full-size route and text, effective label size checked | Silent shrink to illegibility |
| Small API correction | One changed argument | Updates contract/examples without unrelated visual churn | Forces hero images, charts or renderer installation |
| No renderer | Mermaid source, unavailable toolchain | Delivers source with explicit unverified render/visual gates and completes source review | Invented export/screenshot or unauthorized installation/upload |

Use realistic requests and minimal raw sources. For an independent evaluation,
do not provide intended answers. Isolate generated artifacts from skill/product
sources. Record inputs, outputs, method, actual renderer/viewports/themes, results
and gaps. A source-only review is not a render test, accessibility certification,
reader study or guarantee of future beauty.

Apply all relevant visual-quality.md gates; do not average away blockers.
Distinguish decision review, syntax parsing, rendering, visual inspection and
reader-task completion. Real defects override completed checklists; correct and
recheck the actual affected artifact.
