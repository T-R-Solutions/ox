# Measure reduction without inventing savings

Record byte count and character count separately. A tokenizer count needs tokenizer identity/version, model compatibility and the exact serialized content counted. A heuristic such as bytes divided by four is an estimate with unknown error for arbitrary languages or binary data.

Compare original and transformed payloads under the same method. Include any wrapper, tool schema and retrieved follow-up details when the claimed scope includes them. If the CLI runs commands outside the observed pipeline, do not extrapolate savings to those commands.

Provider-reported usage is a different measurement from local tokenization. Price, cache rules and task-quality effects may change cost even with fewer visible tokens. Use paired authorized trials to assess downstream utility; a smaller string alone proves neither lower billing nor better task success. When provider information is absent, report billing savings unavailable.
