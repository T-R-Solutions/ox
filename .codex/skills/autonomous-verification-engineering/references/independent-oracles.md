# Challenge the oracle

Choose an independently specified invariant: a known input/output pair, a protocol rule, a conserved quantity or a forbidden effect. A second implementation copied from the first is not automatically independent; neither is another agent repeating the same premise.

Construct a representative defect that matters to the claim. For a freshness gate, alter a bound file after recording a passing result. For permission separation, give a passing artifact to a deployment mock without a grant. For skipped tests, return an empty test set with wrapper exit zero. Observe the gate refuse approval in all relevant cases.

Keep mutation confined to disposable fixtures. A mock can show that a decision path rejects a missing permission; only an authorized integration can show that a real publication endpoint enforces it. Report both layers distinctly. Do not replace the original acceptance criterion with the easier mock property.
